**libfdtd-cuda: A 2D TMz electromagnetic wave simulation library using FDTD with serial, OpenMP and CUDA backends**

[![License](https://img.shields.io/badge/License-GPLv3.0-blue)](LICENSE)

</div>

---

**fdtd-cuda** is a C++20 library for 2D TMz electromagnetic wave simulation on a Yee grid, with a split-field PML and PEC or PMC outer boundaries. The same simulation runs on a serial, an OpenMP or a CUDA backend. It is a sister project to [fdtd-openmp](https://github.com/yanevskiv/fdtd-openmp), built to practice HPC on the GPU.

> Work in progress. Nothing is usable yet.
